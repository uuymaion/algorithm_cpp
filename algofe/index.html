解法拆解

    
看最左邊怎麼放

    
2×N 的最左邊只有兩種放法：

    
    
      
  • 直放一塊：佔掉寬度 1，剩下 2×(N−1) → f(N−1) 種
    • 
      
  • 橫放兩塊（上下疊）：佔掉寬度 2，剩下 2×(N−2) → f(N−2) 種。只橫放一塊的話，它下面那格只能再放一塊橫的，所以橫的一定成對出現
    • 
    

    
f(1) = 1，f(2) = 2
f(N) = f(N−1) + f(N−2)          ← 就是費氏數列（往後錯一位）

    
為什麼要記憶化？

    
直接遞迴，f(N) 會呼叫 f(N−1) 和 f(N−2)，f(N−1) 又呼叫 f(N−2)… 同一個值被算非常多次，呼叫次數大約是 1.6^N。N = 90 時算不完。存起來之後每個值只算一次，O(N)

    
f(90) = 4,660,046,610,375,530,309，大約 4.66×10¹⁸，int 裝不下，long long（上限約 9.22×10¹⁸）剛好裝得下。你用 #define int long long 是對的

    
N = 0 是結束條件，所以不用輸出。如果題目要求 N = 0 也要輸出，答案是 1（什麼都不放也算一種）

解法拆解

    
為什麼是中位數？

    
想像 w 往上移一格：在 w 下面的井，支管各變長 1；在 w 上面的井，各變短 1。所以：

    
    
      
  • 下面的井比上面多 → 往上移會變長，該往下
    • 
      
  • 上面的井比下面多 → 往上移會變短，該往上
    • 
      
  • 上下一樣多 → 停在這裡最好 → 這就是中位數
    • 
    

    
奇數 vs 偶數

    
N 奇數：最佳 w 只有一個 = 排序後的 y[N/2]
N 偶數：y[N/2−1] 到 y[N/2] 之間的任何 w 總長都一樣
        → 題目要最小的 → y[N/2−1]
合起來：w = y[(N−1)/2]

    
你的程式在偶數時的問題

    
第 36 行 if(onef>two)：本來應該比較兩個總長 onef 和 twof，但打成了 two（那是 index）。總長一定比 index 大，所以每次都選 one（上面那個中位數）。可是偶數時兩邊總長一樣，題目要的是比較小的那個

    
y = 1 3       正確：1 2     你的：3 2
y = 1 2 10 20 正確：2 27    你的：10 27

    
修法最簡單的是直接用 ansid = (n - 1) / 2，不用分奇偶。或是保留原本的結構，把第 36 行改成 if (onef < twof)，相等時就會走 else 選到比較小的 two

    
複雜度：排序 O(N log N)。另外 findmid 每次 O(N)，最多呼叫 2 次，沒問題

解法拆解

    
這就是 Prim 演算法

    
Prim 求最小生成樹的流程是：從一個點開始，每次挑「連到目前這棵樹的邊裡最好的那條」，把另一端加進來。這題一模一樣，只是「最好」的定義變了：

    
Prim（最小生成樹）：選權重最小的邊
這題：               選 freq 最大的邊，freq 相同選 dis 最小的

    
實作（O(n²) 版本，n ≤ 200 綽綽有餘）

    
    
      
  1. 每個城市記 bestF[v]、bestD[v]：目前連到已感染城市的路裡，最好的那條的 freq 和 dis。一開始是「沒有」
    2. 
      
  2. 感染起點，用它的所有邊更新鄰居的 best
    3. 
      
  3. 重複：在還沒感染、而且 best 不是「沒有」的城市裡，挑 (freq 大, dis 小) 最好的那個
    4. 
      
  4. 感染它、輸出它，再用它的邊更新鄰居
    5. 
      
  5. 挑不到就結束
    6. 
    

    
每輪掃 n 個城市挑最好的 O(n)，共 n 輪 → O(n²)；更新鄰居總共 O(m)。如果 n 很大，可以改成 priority_queue，O(m log m)

    
「比較兩條路」要寫成：f1 > f2 || (f1 == f2 && d1 < d2)。先比 freq（大的好），一樣才比 dis（小的好）

變數命名小提醒：你用 left/right 判斷 i（列）、up/down 判斷 j（行），跟直覺相反（通常上下是列、左右是行）。邏輯是對的，只是之後回頭看容易搞混

int dx[8] = {-1, 1, 0, 0, -1, -1, 1, 1};
int dy[8] = { 0, 0,-1, 1, -1,  1,-1, 1};
for (int k = 0; k < 8; k++) {
    int x = i + dx[k], y = j + dy[k];
    if (x < 0 || x >= n || y < 0 || y >= m) continue;
    arr[x][y] = max(arr[x][y], k < 4 ? d1 : d2);
}
